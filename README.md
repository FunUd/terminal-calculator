# Terminal Calculator (TUI 電卓)

Windows 11 向けのキーボード中心の数式入力型 TUI 電卓です。
関数電卓とプログラマー電卓の機能を統合し、DEC / HEX / BIN / OCT および Signed / Unsigned 16/32/64-bit 解釈を常時表示します。

## 主な特徴

- **左右2ペイン統合UI**:
  - **左ペイン**: 数式入力、DEC / HEX / BIN / OCT / 16/32/64-bit Signed / Unsigned リアルタイム結果パネル
  - **右ペイン**: 通し番号付き履歴リスト (`#1`, `#2`...)、**64-bit ビット視覚化グリッド**、キー＆関数クイックリファレンス
- **履歴値の再利用 (`ans` / `h1`..`hN` / `$1`..`$N`)**:
  - `ans`: 直前の計算結果（例: `ans * 2`）
  - `h1`, `h2`... または `$1`, `$2`...: 過去の履歴番号の結果を現在の式で直接参照（例: `h1 + h2`）
- **安全な計算エンジン**: `eval()` や `exec()` を一切使用せず、許可リスト方式の独自トークナイザー・再帰下降パーサー・AST 評価器を実装。
- **統合型基数・符号表示**:
  - DEC (10進数)、HEX (`0x` 16進数)、BIN (`0b` 4桁区切り2進数)、OCT (`0o` 8進数) をリアルタイム同時表示。
  - 16-bit / 32-bit / 64-bit Signed (2の補数) および Unsigned 解釈を同時表示し、オーバーフロー時には警告を表示。
  - 任意精度整数の算術結果と各ビット幅の表現を明確に分離。
- **レインボー括弧ハイライト (Rainbow Brackets)**:
  - ネストの深さに応じて括弧をゴールド・シアン・ピンク・グリーン等の色で自動カラーリング。
  - 閉じ忘れや余分な閉じ括弧など、**対応しない不一致括弧を赤色背景で即座に警告表示**。
- **64-bit ビット視覚化グリッド (Bitfield Visualizer)**:
  - 64-bitの各ビット（63..48, 47..32, 31..16, 15..00）の 0/1 パターンと各ワードの HEX 値を常時グラフィカル表示。
- **基数の混在計算**: `0xFF + 10`, `0b1010 * 2`, `sqrt(16) + 0x10` などの混在演算に対応。
- **32-bit ビット演算**: AND (`&`), OR (`|`), XOR (`^`), NOT (`~`), 左シフト (`<<`), 論理右シフト (`>>`)。
- **関数電卓機能**:
  - DEG (度数法) / RAD (弧度法) 切り替え (初期値: DEG)
  - 三角関数 (`sin`, `cos`, `tan`, `asin`, `acos`, `atan`)
  - `sqrt`, `log` (常用対数 底10), `ln` (自然対数 底e), `abs`, `factorial`, `exp`
  - 定数 `pi`, `e`
- **キーボード優先 UI**: リアルタイム計算プレビュー、上下矢印による入力履歴のナビゲーション。

## 動作要件・技術スタック

- **OS**: Windows 11 (Windows Terminal 推奨)
- **Python**: 3.12 以上
- **パッケージマネージャー**: `uv`
- **UI フレームワーク**: `Textual`
- **テストフレームワーク**: `pytest`, `pytest-asyncio`, `pytest-cov`

## Windows 11 での起動方法

1. **uv のインストール** (未導入の場合):
   PowerShell で以下を実行します。
   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```

2. **依存関係の同期**:
   ```powershell
   uv sync
   ```

3. **電卓の起動**:
   ```powershell
   uv run calc
   ```
   または
   ```powershell
   uv run tc
   ```
   または
   ```powershell
   uv run python -m calc
   ```

## `uv run` なしで起動するには

### 方法1: PATHを通す（開発中におすすめ）

プロジェクトの仮想環境をPATHに追加することで、どこからでも `tc` コマンドで起動できます。

#### Windows (PowerShell)

**一時的にPATHに追加（現在のセッションのみ）:**
```powershell
$env:PATH += ";$PWD\.venv\Scripts"
tc
```

**永続的に追加（再起動後も有効）:**
```powershell
# $PWD を実際のプロジェクトパスに置き換えてください
[System.Environment]::SetEnvironmentVariable(
    "Path",
    [System.Environment]::GetEnvironmentVariable("Path", "User") + ";C:\Users\Yudai\Desktop\github\terminal-calculator\.venv\Scripts",
    "User"
)
```

### 方法2: グローバルツールとしてインストール（編集可能モード）

`uv tool install --editable` を使用すると、グローバルにインストールしつつ、コードの変更が即座に反映されます。

```powershell
uv tool install --editable .
```

これで、どのディレクトリからでも `tc` だけで起動でき、コードを変更すると自動的に反映されます。

**アンインストールする場合:**
```powershell
uv tool uninstall terminal-calculator
```

## 設定の永続化

テーマや角度モードなどの設定は、アプリケーション終了時に自動的に保存され、次回起動時に復元されます。

設定ファイルの場所:
- Windows: `C:\Users\<ユーザー名>\.config\terminal-calculator\config.json`

設定項目:
- `angle_mode`: DEG (度数法) または RAD (弧度法)
- `theme`: Textualのテーマ名 (default, textual-dark, textual-light など)
- `max_history`: 履歴の最大保存数 (デフォルト: 100)

## キーボード操作

| キー | 動作 |
|---|---|
| **Enter** | 入力中の式を確定し、履歴リストに追加 |
| **↑ / ↓** | 入力欄で過去の履歴を呼び出し・ドラフトへ復帰 |
| **F1 / ?** | 詳細ヘルプ＆リファレンス画面を表示 (Esc/Enterで閉じる) |
| **F2** | 角度モード切替 (DEG ⇔ RAD) |
| **F3** | テーマ切替 (Textualの組み込みテーマを巡回) |
| **F4** | クリップボードにコピー |
| **Esc / Ctrl+L** | 入力欄をクリア |
| **Ctrl+Q** | アプリケーション終了 |
| **Tab** | 入力欄と履歴一覧間のフォーカス移動（クリック選択も可能） |

## 計算式の構文例

### 1. 算術演算 & 履歴変数の参照
- `2 + 3 * 4` → `14`
- `ans * 2` → 直前の計算結果（14）× 2 = `28`
- `h1 + 10` または `$1 + 10` → 履歴 #1 の結果 + 10
- `2 ** 3 ** 2` → `512` (右結合)
- `-2 ** 2` → `-4` (べき乗が単項マイナスより高優先)
- `7 // 3` → `2` (整数除算)
- `7 % 3` → `1` (剰余)
- `7 / 2` → `3.5` (浮動小数点除算)

### 2. 基数混在リテラル
- `0xFF + 10` → `265`
- `0b1010 * 2` → `20`
- `0o17 + 1` → `16`
- `3.14 * 2` → `6.28`
- `1.2e-3 * 1000` → `1.2`

### 3. 32-bit ビット演算
- `0xFF & 0x0F` → `0x0F`
- `0xF0 | 0x0F` → `0xFF`
- `0xFF ^ 0x0F` → `0xF0`
- `~0` → `0xFFFFFFFF`
- `0x80000000 >> 1` → `0x40000000` (符号なし論理右シフト)
- `1 << 4` → `16`

### 4. 数学関数 & 定数
- `sqrt(16)` → `4` (完全平方数は整数として返却)
- `16 ** 0.5` または `16 ** (1/2)` → `4.0` (べき乗による平方根計算)
- `sqrt(16) + 0x10` → `20`
- `sin(30)` (DEG モード) → `0.5`
- `sin(pi / 6)` (RAD モード) → `0.5`
- `log(100)` → `2` (底10)
- `ln(e)` → `1` (底e)
- `factorial(5)` → `120`

## 既知の制約・安全性設計

1. **計算負荷保護**:
   - べき乗の指数は絶対値 `10,000` を上限として制限しています。
   - 階乗 `factorial(n)` は `0 <= n <= 1,000` の整数に制限しています。
2. **ビット演算の対象**:
   - ビット演算 (`&`, `|`, `^`, `~`, `<<`, `>>`) は整数のみを対象とします。浮動小数点を指定するとエラーとなります。
   - シフト量は `0` ～ `31` に制限されます。
3. **浮動小数点の基数表示**:
   - 仕様に基づき、浮動小数点数の計算結果には HEX / BIN / OCT / Signed / Unsigned 32-bit の変換は適用されず `N/A` 表示となります。
